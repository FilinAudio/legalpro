# Решение Совета директоров Банка России от 16.05.2025 "Об уровнях кредитных рейтингов, устанавливаемых в соответствии с Указанием Банка России от 2 августа 2021 года N 5873-У"

В СООТВЕТСТВИИ С УКАЗАНИЕМ БАНКА РОССИИ

ОТ 2 АВГУСТА 2021 ГОДА N 5873-У

Совет директоров Банка России 16 мая 2025 года принял решение:

1. В целях применения главы 3 (за исключением абзаца восьмого подпункта 3.7.2.1, абзацев шестого и седьмого подпункта 3.7.3, абзацев восьмого и девятого подпункта 3.7.6.2, абзацев восьмого и девятого подпункта 3.7.8, абзаца второго подпункта 3.7.11 пункта 3.7) Указания Банка России от 2 августа 2021 года N 5873-У "Об установлении обязательного норматива достаточности капитала для профессиональных участников рынка ценных бумаг, осуществляющих дилерскую, брокерскую деятельность, деятельность по управлению ценными бумагами и деятельность форекс-дилеров" (далее - Указание Банка России N 5873-У) установить следующие уровни кредитных рейтингов:

в отношении российских объектов рейтинга - "BBB+(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruBBB+" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "BBB+.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "BBB+|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА";

в отношении иностранных объектов рейтинга - "B1" по международной рейтинговой шкале Moody's Investors Service, либо "B+" по международной рейтинговой шкале S&P Global Ratings, либо "B+" по международной рейтинговой шкале Fitch Ratings, либо "B+" по международной рейтинговой шкале АКРА (АО).

2. В целях применения абзаца восьмого подпункта 3.7.2.1, абзацев шестого и седьмого подпункта 3.7.3, абзацев восьмого и девятого подпункта 3.7.6.2, абзацев восьмого и девятого подпункта 3.7.8 пункта 3.7 Указания Банка России N 5873-У установить следующие уровни кредитных рейтингов для российских объектов рейтинга: "AAA(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruAAA" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "AAA.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "AAA|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА".

3. В целях применения абзаца второго подпункта 3.7.11 пункта 3.7 Указания Банка России N 5873-У установить следующие уровни кредитных рейтингов для российских объектов рейтинга: "BBB+(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruBBB+" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "BBB+.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "BBB+|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА".

4. В целях применения абзацев тринадцатого - пятнадцатого подпункта 5.4.5 пункта 5.4 Указания Банка России N 5873-У установить следующие уровни кредитных рейтингов для российских объектов рейтинга: "AAA(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruAAA" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "AAA.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "AAA|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА".

5. В целях применения абзацев шестнадцатого - восемнадцатого подпункта 5.4.5 пункта 5.4 Указания Банка России N 5873-У установить следующие уровни кредитных рейтингов для российских объектов рейтинга: от "AA(RU)" до "AAA(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо от "ruAA" до "ruAAA" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо от "AA.ru" до "AAA.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо от "AA+|ru|" до "AAA|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА".

6. В целях применения абзацев девятнадцатого - двадцать первого подпункта 5.4.5 пункта 5.4 Указания Банка России N 5873-У установить следующие уровни кредитных рейтингов для российских объектов рейтинга: от "AA-(RU)" и ниже по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо от "ruAA-" и ниже по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо от "AA-.ru" и ниже по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо от "AA|ru|" и ниже по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА".

7. В целях применения главы 7 Указания Банка России N 5873-У установить следующие уровни кредитных рейтингов:

7.1. Для I категории качества:

в отношении российских объектов рейтинга - "AAA(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruAAA" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "AAA.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "AAA|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА";

в отношении иностранных объектов рейтинга - "Baa3" по международной рейтинговой шкале Moody's Investors Service, либо "BBB-" по международной рейтинговой шкале S&P Global Ratings, либо "BBB-" по международной рейтинговой шкале Fitch Ratings, либо "BBB-" по международной рейтинговой шкале АКРА (АО).

7.2. Для II категории качества:

в отношении российских объектов рейтинга - "BBB+(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruBBB+" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "BBB+.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "BBB+|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА";

в отношении иностранных объектов рейтинга - "B1" по международной рейтинговой шкале Moody's Investors Service, либо "B+" по международной рейтинговой шкале S&P Global Ratings, либо "B+" по международной рейтинговой шкале Fitch Ratings, либо "B+" по международной рейтинговой шкале АКРА (АО).

8. Использовать для целей настоящего решения следующие виды кредитных рейтингов кредитных рейтинговых агентств АКРА (АО), АО "Эксперт РА", ООО "НКР" и ООО "НРА":

АКРА (АО) - кредитные рейтинги, присвоенные по национальной рейтинговой шкале для Российской Федерации, а также кредитные рейтинги, присвоенные по международной рейтинговой шкале международным финансовым институтам;

АО "Эксперт РА" - кредитные рейтинги, присвоенные по национальной рейтинговой шкале для Российской Федерации;

ООО "НКР" - кредитные рейтинги банков, кредитные рейтинги нефинансовых компаний, присвоенные по национальной рейтинговой шкале для Российской Федерации;

ООО "НРА" - кредитные рейтинги банков, кредитные рейтинги нефинансовых компаний, присвоенные по национальной рейтинговой шкале для Российской Федерации.

9. Применять настоящее решение со дня его опубликования на официальном сайте Банка России в информационно-телекоммуникационной сети "Интернет".

10. Со дня опубликования настоящего решения отменить решение Совета директоров Банка России от 27 октября 2023 года "Об уровнях кредитных рейтингов, устанавливаемых в соответствии с Указанием Банка России от 2 августа 2021 года N 5873-У", опубликованное на официальном сайте Банка России в информационно-телекоммуникационной сети "Интернет" 3 ноября 2023 года.
