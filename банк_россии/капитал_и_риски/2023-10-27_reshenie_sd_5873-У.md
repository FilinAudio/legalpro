КРЕДИТНЫХ РЕЙТИНГОВ, УСТАНАВЛИВАЕМЫХ

В СООТВЕТСТВИИ С УКАЗАНИЕМ БАНКА РОССИИ ОТ 2 АВГУСТА

2021 ГОДА N 5873-У

Совет директоров Банка России 27 октября 2023 года принял решение:

1. В целях применения главы 3 (за исключением абзаца восьмого подпункта 3.7.2.1, абзацев шестого и седьмого подпункта 3.7.3, абзацев восьмого и девятого подпункта 3.7.6.2, абзацев восьмого и девятого подпункта 3.7.8, абзаца второго подпункта 3.7.11 пункта 3.7) Указания Банка России от 2 августа 2021 года N 5873-У "Об установлении обязательного норматива достаточности капитала для профессиональных участников рынка ценных бумаг, осуществляющих дилерскую, брокерскую деятельность, деятельность по управлению ценными бумагами и деятельность форекс-дилеров" (далее - Указание Банка России N 5873-У) установить следующие уровни кредитных рейтингов:

в отношении российских объектов рейтинга - "BBB+(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruBBB+" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "BBB+.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "BBB+|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА";

в отношении иностранных объектов рейтинга - "B1" по международной рейтинговой шкале Moody's Investors Service, либо "B+" по международной рейтинговой шкале S&P Global Ratings, либо "B+" по международной рейтинговой шкале Fitch Ratings.

2. В целях применения абзаца восьмого подпункта 3.7.2.1, абзацев шестого и седьмого подпункта 3.7.3, абзацев восьмого и девятого подпункта 3.7.6.2, абзацев восьмого и девятого подпункта 3.7.8 пункта 3.7 Указания Банка России N 5873-У установить следующие уровни кредитных рейтингов для российских объектов рейтинга: "AAA(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruAAA" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "AAA.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "AAA|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА".

3. В целях применения абзаца второго подпункта 3.7.11 пункта 3.7 Указания Банка России N 5873-У установить следующие уровни кредитных рейтингов для российских объектов рейтинга: "BBB+(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruBBB+" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "BBB+.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "BBB+|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА".

4. В целях применения главы 7 Указания Банка России N 5873-У установить следующие уровни кредитных рейтингов:

4.1. Для I категории качества:

в отношении российских объектов рейтинга - "AAA(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruAAA" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "AAA.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "AAA|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА";

в отношении иностранных объектов рейтинга - "Baa3" по международной рейтинговой шкале Moody's Investors Service, либо "BBB-" по международной рейтинговой шкале S&P Global Ratings, либо "BBB-" по международной рейтинговой шкале Fitch Ratings.

4.2. Для II категории качества:

в отношении российских объектов рейтинга - "BBB+(RU)" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АКРА (АО), либо "ruBBB+" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства АО "Эксперт РА", либо "BBB+.ru" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НКР", либо "BBB+|ru|" по национальной рейтинговой шкале для Российской Федерации кредитного рейтингового агентства ООО "НРА";

в отношении иностранных объектов рейтинга - "B1" по международной рейтинговой шкале Moody's Investors Service, либо "B+" по международной рейтинговой шкале S&P Global Ratings, либо "B+" по международной рейтинговой шкале Fitch Ratings.

5. Использовать для целей настоящего решения следующие виды кредитных рейтингов кредитных рейтинговых агентств АКРА (АО), АО "Эксперт РА", ООО "НКР" и ООО "НРА":

АКРА (АО) - кредитные рейтинги, присвоенные по национальной рейтинговой шкале для Российской Федерации;

АО "Эксперт РА" - кредитные рейтинги, присвоенные по национальной рейтинговой шкале для Российской Федерации;

ООО "НКР" - кредитные рейтинги банков, кредитные рейтинги нефинансовых компаний, присвоенные по национальной шкале для Российской Федерации;

ООО "НРА" - кредитные рейтинги банков, кредитные рейтинги нефинансовых компаний, присвоенные по национальной шкале для Российской Федерации.

6. Применять настоящее решение с даты его опубликования на официальном сайте Банка России в информационно-телекоммуникационной сети "Интернет".

7. Со дня опубликования настоящего решения не применять решение Совета директоров Банка России от 22 июля 2022 года "Об установлении уровней кредитных рейтингов в целях применения Указания Банка России от 2 августа 2021 года N 5873-У", информация о котором опубликована на официальном сайте Банка России в информационно-телекоммуникационной сети "Интернет" 26 июля 2022 года.
