# Решение Совета директоров Банка России от 19.12.2025 "Об установлении уровней кредитного рейтинга в соответствии с подпунктами 2 и 3 пункта 2 статьи 3.1 Федерального закона от 22 апреля 1996 года N 39-ФЗ "О рынке ценных бумаг"

СОВЕТ ДИРЕКТОРОВ

РЕШЕНИЕ

от 19 декабря 2025 года

ОБ УСТАНОВЛЕНИИ

УРОВНЕЙ КРЕДИТНОГО РЕЙТИНГА В СООТВЕТСТВИИ С ПОДПУНКТАМИ 2

И 3 ПУНКТА 2 СТАТЬИ 3.1 ФЕДЕРАЛЬНОГО ЗАКОНА ОТ 22 АПРЕЛЯ

1996 ГОДА N 39-ФЗ "О РЫНКЕ ЦЕННЫХ БУМАГ"

Совет директоров Банка России 19 декабря 2025 года принял решение:

1. В соответствии с подпунктом 2 пункта 2 статьи 3.1 Федерального закона от 22 апреля 1996 года N 39-ФЗ "О рынке ценных бумаг" (далее - Закон N 39-ФЗ) установить следующие уровни кредитного рейтинга облигаций (за исключением облигаций, указанных в пункте 2 настоящего решения), их эмитента или лица, предоставившего обеспечение по указанным облигациям: "ruA+" по национальной рейтинговой шкале для Российской Федерации АО "Эксперт РА" (далее - национальная шкала АО "Эксперт РА"), либо "A+(RU)" по национальной рейтинговой шкале для Российской Федерации АКРА (АО) (далее - национальная шкала АКРА (АО), либо "A+.ru" по национальной рейтинговой шкале для Российской Федерации ООО "НКР" (далее - национальная шкала ООО "НКР"), либо "A+|ru|" по национальной рейтинговой шкале для Российской Федерации ООО "НРА" (далее - национальная шкала ООО "НРА"), присвоенные облигациям (за исключением облигаций, указанных в пункте 2 настоящего решения), их эмитентам или лицам, предоставившим обеспечение по указанным облигациям, как минимум двумя кредитными рейтинговыми агентствами.

2. В соответствии с подпунктом 2 пункта 2 статьи 3.1 Закона N 39-ФЗ установить следующие уровни кредитного рейтинга облигаций с ипотечным покрытием: "ruAAA.sf" по национальной рейтинговой шкале АО "Эксперт РА" для Российской Федерации, применяемой для присвоения кредитных рейтингов инструментам структурированного финансирования, и "AAA(ru.sf)" по национальной рейтинговой шкале сектора структурированного финансирования для Российской Федерации АКРА (АО), присвоенные облигациям с ипотечным покрытием одновременно двумя кредитными рейтинговыми агентствами.

Установить для эмитента облигаций с ипотечным покрытием следующие уровни кредитного рейтинга: "ruAAA" по национальной шкале АО "Эксперт РА" и "AAA(RU)" по национальной шкале АКРА (АО), присвоенные эмитенту облигаций с ипотечным покрытием одновременно двумя кредитными рейтинговыми агентствами.

Установить для лица, предоставившего обеспечение по облигациям с ипотечным покрытием, следующие уровни кредитного рейтинга: "ruAAA" по национальной шкале АО "Эксперт РА", либо "AAA(RU)" по национальной шкале АКРА (АО), либо "AAA.ru" по национальной шкале ООО "НКР", либо "AAA|ru|" по национальной шкале ООО "НРА", присвоенные лицу, предоставившему обеспечение по облигациям с ипотечным покрытием, как минимум двумя кредитными рейтинговыми агентствами.

3. В соответствии с подпунктом 3 пункта 2 статьи 3.1 Закона N 39-ФЗ установить следующие уровни кредитного рейтинга юридического лица, созданного в соответствии с законодательством Российской Федерации, за счет которого обеспечивается или осуществляется исполнение обязательств по облигациям: "ruA+" по национальной шкале АО "Эксперт РА", либо "A+(RU)" по национальной шкале АКРА (АО), либо "A+.ru" по национальной шкале ООО "НКР", либо "A+|ru|" по национальной шкале ООО "НРА", присвоенные указанному юридическому лицу как минимум двумя кредитными рейтинговыми агентствами.

4. Использовать для целей настоящего решения следующие виды кредитных рейтингов кредитных рейтинговых агентств АО "Эксперт РА", АКРА (АО), ООО "НКР" и ООО "НРА":

АО "Эксперт РА" - кредитные рейтинги, присвоенные по национальной рейтинговой шкале для Российской Федерации или по национальной рейтинговой шкале для Российской Федерации, применяемой для присвоения кредитных рейтингов инструментам структурированного финансирования;

АКРА (АО) - кредитные рейтинги, присвоенные по национальной рейтинговой шкале для Российской Федерации или по национальной рейтинговой шкале сектора структурированного финансирования для Российской Федерации;

ООО "НКР" - кредитные рейтинги банков, кредитные рейтинги нефинансовых компаний, кредитные рейтинги долговых обязательств, присвоенные по национальной рейтинговой шкале для Российской Федерации;

ООО "НРА" - кредитные рейтинги банков, кредитные рейтинги нефинансовых компаний, присвоенные по национальной рейтинговой шкале для Российской Федерации.

5. Применять настоящее решение с 1 июля 2026 года.

6. С 1 июля 2026 года отменить решение Совета директоров Банка России от 14 февраля 2025 года "Об установлении уровней кредитного рейтинга в целях применения подпунктов 2 и 3 пункта 2 статьи 3.1 Федерального закона от 22 апреля 1996 года N 39-ФЗ "О рынке ценных бумаг", опубликованное на официальном сайте Банка России в информационно-телекоммуникационной сети "Интернет" 20 февраля 2025 года.
