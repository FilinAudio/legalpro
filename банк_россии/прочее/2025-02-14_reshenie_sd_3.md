# Решение Совета директоров Банка России от 14.02.2025 "Об установлении уровней кредитного рейтинга в целях применения подпунктов 2 и 3 пункта 2 статьи 3.1 Федерального закона от 22 апреля 1996 года N 39-ФЗ "О рынке ценных бумаг"

от 14 февраля 2025 года

ОБ УСТАНОВЛЕНИИ

УРОВНЕЙ КРЕДИТНОГО РЕЙТИНГА В ЦЕЛЯХ ПРИМЕНЕНИЯ

ПОДПУНКТОВ 2 И 3 ПУНКТА 2 СТАТЬИ 3.1 ФЕДЕРАЛЬНОГО ЗАКОНА

ОТ 22 АПРЕЛЯ 1996 ГОДА N 39-ФЗ "О РЫНКЕ ЦЕННЫХ БУМАГ"

Совет директоров Банка России 14 февраля 2025 года принял решение:

1. В целях применения подпункта 2 пункта 2 статьи 3.1 Федерального закона от 22 апреля 1996 года N 39-ФЗ "О рынке ценных бумаг" (далее - Закон N 39-ФЗ) установить следующие уровни кредитного рейтинга облигаций (за исключением облигаций, указанных в пунктах 2 и 3 настоящего решения), их эмитента или лица, предоставившего обеспечение по указанным облигациям: "ruА+" по национальной рейтинговой шкале для Российской Федерации АО "Эксперт РА" (далее - национальная шкала АО "Эксперт РА"), либо "А+(RU)" по национальной рейтинговой шкале для Российской Федерации АКРА (АО) (далее - национальная шкала АКРА (АО), либо "А+.ru" по национальной рейтинговой шкале для Российской Федерации ООО "НКР" (далее - национальная шкала ООО "НКР"), либо "А+|ru|" по национальной рейтинговой шкале для Российской Федерации ООО "НРА" (далее - национальная шкала ООО "НРА").

2. В целях применения подпункта 2 пункта 2 статьи 3.1 Закона N 39-ФЗ установить следующие уровни кредитного рейтинга облигаций с ипотечным покрытием: "ruAAA.sf" по национальной рейтинговой шкале АО "Эксперт РА" для Российской Федерации, применяемой для присвоения кредитных рейтингов инструментам структурированного финансирования, либо "AAA(ru.sf)" по национальной рейтинговой шкале сектора структурированного финансирования для Российской Федерации АКРА (АО).

Установить для эмитента указанных облигаций следующие уровни кредитного рейтинга: "ruAAA" по национальной шкале АО "Эксперт РА" либо "AAA(RU)" по национальной шкале АКРА (АО).

Установить для лица, предоставившего обеспечение по указанным облигациям, следующие уровни кредитного рейтинга: "ruAAA" по национальной шкале АО "Эксперт РА", либо "AAA(RU)" по национальной шкале АКРА (АО), либо "AAA.ru" по национальной шкале ООО "НКР", либо "AAA|ru|" по национальной шкале ООО "НРА".

3. В целях применения подпункта 2 пункта 2 статьи 3.1 Закона N 39-ФЗ установить до 22 мая 2025 года включительно следующие уровни кредитного рейтинга облигаций специализированных обществ, обеспеченных залогом прав (требований) по кредитным договорам, договорам займа и (или) иным обязательствам субъектов малого и среднего предпринимательства: "ruAAA.sf" по национальной рейтинговой шкале АО "Эксперт РА" для Российской Федерации, применяемой для присвоения кредитных рейтингов инструментам структурированного финансирования, либо "AAA(ru.sf)" по национальной рейтинговой шкале сектора структурированного финансирования для Российской Федерации АКРА (АО).

Установить для эмитента указанных облигаций следующие уровни кредитного рейтинга: "ruAAA" по национальной шкале АО "Эксперт РА" либо "AAA(RU)" по национальной шкале АКРА (АО).

Установить для лица, предоставившего обеспечение по указанным облигациям, следующие уровни кредитного рейтинга: "ruAAA" по национальной шкале АО "Эксперт РА", либо "AAA(RU)" по национальной шкале АКРА (АО), либо "AAA.ru" по национальной шкале ООО "НКР", либо "AAA|ru|" по национальной шкале ООО "НРА".

4. В целях применения подпункта 3 пункта 2 статьи 3.1 Закона N 39-ФЗ установить следующие уровни кредитного рейтинга юридического лица, созданного в соответствии с законодательством Российской Федерации и за счет которого обеспечивается или осуществляется исполнение обязательств по облигациям: "ruА+" по национальной шкале АО "Эксперт РА", либо "А+(RU)" по национальной шкале АКРА (АО), либо "А+.ru" по национальной шкале ООО "НКР", либо "А+|ru|" по национальной шкале ООО "НРА".

5. Использовать для целей настоящего решения следующие виды кредитных рейтингов кредитных рейтинговых агентств АО "Эксперт РА", АКРА (АО), ООО "НКР" и ООО "НРА":

АО "Эксперт РА" - кредитные рейтинги, присвоенные по национальной рейтинговой шкале для Российской Федерации или по национальной рейтинговой шкале для Российской Федерации, применяемой для присвоения кредитных рейтингов инструментам структурированного финансирования;

АКРА (АО) - кредитные рейтинги, присвоенные по национальной рейтинговой шкале для Российской Федерации или по национальной рейтинговой шкале сектора структурированного финансирования для Российской Федерации;

ООО "НКР" - кредитные рейтинги банков, кредитные рейтинги нефинансовых компаний, кредитные рейтинги долговых обязательств, присвоенные по национальной рейтинговой шкале для Российской Федерации;

ООО "НРА" - кредитные рейтинги банков, кредитные рейтинги нефинансовых компаний, присвоенные по национальной рейтинговой шкале для Российской Федерации.

6. Применять настоящее решение со дня его опубликования на официальном сайте Банка России в информационно-телекоммуникационной сети "Интернет".

7. Со дня опубликования настоящего решения отменить:

решение Совета директоров Банка России от 23 июля 2021 года "Об установлении уровней кредитного рейтинга в целях применения подпунктов 2 и 3 пункта 2 статьи 3.1 Федерального закона от 22.04.1996 N 39-ФЗ "О рынке ценных бумаг", опубликованное на официальном сайте Банка России в информационно-телекоммуникационной сети "Интернет" 23 июля 2021 года;

решение Совета директоров Банка России от 23 декабря 2021 года "Об установлении уровней кредитного рейтинга облигаций с ипотечным покрытием в целях применения подпункта 2 пункта 2 статьи 3.1 Федерального закона от 22.04.1996 N 39-ФЗ "О рынке ценных бумаг", опубликованное на официальном сайте Банка России в информационно-телекоммуникационной сети "Интернет" 23 декабря 2021 года.
