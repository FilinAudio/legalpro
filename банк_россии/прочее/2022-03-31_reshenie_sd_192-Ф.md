ЗАКОНОДАТЕЛЬНЫЕ АКТЫ РОССИЙСКОЙ ФЕДЕРАЦИИ"

Совет директоров Банка России 31 марта 2022 года принял решение:

1. В целях применения подпункта "в" пункта 1 части 13 статьи 11 Федерального закона от 11.06.2021 N 192-ФЗ "О внесении изменений в отдельные законодательные акты Российской Федерации" установить следующие уровни кредитного рейтинга облигаций (при отсутствии кредитного рейтинга облигаций - кредитного рейтинга их эмитента, поручителя (гаранта) по облигациям):

- "ruАА-" по национальной рейтинговой шкале для Российской Федерации Акционерного общества "Рейтинговое агентство "Эксперт РА" (далее - АО "Эксперт РА");

- "АА-(RU)" по национальной рейтинговой шкале для Российской Федерации Аналитического Кредитного Рейтингового Агентства (Акционерное общество) (далее - АКРА (АО);

- "АА-.ru" по национальной рейтинговой шкале для Российской Федерации Общества с ограниченной ответственностью "Национальные Кредитные Рейтинги" (далее - ООО "НКР").

2. Использовать следующие виды кредитных рейтингов кредитных рейтинговых агентств АО "Эксперт РА", АКРА (АО) и ООО "НКР":

кредитные рейтинги АО "Эксперт РА" - кредитные рейтинги, присвоенные по национальной рейтинговой шкале для Российской Федерации;

кредитные рейтинги АКРА (АО) - кредитные рейтинги, присвоенные по национальной рейтинговой шкале для Российской Федерации;

кредитные рейтинги ООО "НКР" - кредитные рейтинги банков, кредитные рейтинги нефинансовых компаний, присвоенные по национальной рейтинговой шкале для Российской Федерации.

3. Применять настоящее решение с 1 апреля 2022 года.
