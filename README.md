# legalpro — законодательство о профучастниках и рынке ценных бумаг

Приватный репозиторий. Нормативные акты по регулированию финансовых рынков России (кроме контрсанкционных актов): акты Банка России, федеральные законы, решения регуляторов, акты инфраструктуры рынка и СНГ/ЕАЭС, которые касаются брокеров, дилеров, депозитариев и других профучастников.

Контрсанкционные акты — в репозитории `sanctions-acts-registry`. Документы СРО НФА — в `NFA_acts`, СРО НАУФОР — в `NAUFOR_acts`.

## Связь с санкционным репозиторием

Акты Банка России, которые одновременно регулируют финрынок и входят в санкционный реестр (решения Совета директоров, разъяснения по Указам № 79, 81, 95, 138 и др.), остаются в `sanctions-acts-registry` — папки `законодательство/санкции/05_bank_rossii_resheniya` и `06_bank_rossii_finrynok`. Здесь они не дублируются; при поиске по финрынку смотрите и туда.

## Пополнение

Еженедельная задача проверяет новые акты и раскладывает их по репозиториям: санкционные — в `sanctions-acts-registry`, прочие по финрынкам — сюда, с сайтов НФА и НАУФОР — в `NFA_acts` и `NAUFOR_acts`.

Статус и действующая редакция актов на дату скачивания не проверялись; перед применением сверяйте с первоисточником.
