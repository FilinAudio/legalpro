# legalpro — законодательство о профучастниках и рынке ценных бумаг

Приватный репозиторий. Нормативные акты по регулированию финансовых рынков России (кроме контрсанкционных актов): акты Банка России, федеральные законы, решения регуляторов, акты инфраструктуры рынка и СНГ/ЕАЭС, которые касаются брокеров, дилеров, депозитариев и других профучастников.

Контрсанкционные акты — в репозитории `sanctions-acts-registry`. Документы СРО НФА — в `NFA_acts`, СРО НАУФОР — в `NAUFOR_acts`.
